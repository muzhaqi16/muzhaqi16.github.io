Live on iOS and Android

Local-first writes

A change shows up immediately as an optimistic layer, while the cache holds only what the server said. Writes are saved before they send and replay in order. Client-minted IDs and idempotency keys make a re-send safe, and a refused change is kept for the person to retry or discard. Live updates reach the household over WebSocket subscriptions.

Receipts read on the phone first

Swift and Kotlin native modules recognize the text on the device with Apple Vision and ML Kit, then a rules parser reads it. A reading that adds up stands. Anything else goes to the API, which parses receipts with LLMs and embeddings.

A core that runs without React Native

The data layer, state and domain logic load in Node with no React Native installed, and reach the device only through ports. A test holds that line, so the data layer can be exercised without a device.

One design system

130+ shared components on tokens for color, type, spacing and motion, with light and dark themes, Reanimated and Skia, FlashList, and four languages: English, Spanish, Italian and Albanian.

Rules the tooling enforces

Project rules live in custom ESLint rules and Jest tests, not a style guide. One gate keeps production code at zero React Compiler bailouts, and a rule that depends on a library's behavior cites the version and probe that verified it.
